# Slack Trigger

Lets you message your agent from Slack: mention it in a channel, or send it a
direct message, and its reply comes back in the same thread.

This is the first thing your agent can do that your laptop never could. It only
works on a cloud agent, because Slack has to be able to reach it at a permanent
web address.

Setting it up is three steps in a fixed order, and the order matters. See
[docs/SLACK_TRIGGER.md](../../docs/SLACK_TRIGGER.md).
